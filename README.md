# odin-recipes
First project in The Odin Project.

Objective of this project is to practice basic HTML fundamentals learned through TOP's HTML Foundations section via creating a mock website with a main index page that contains recipes.

Through this project, the skills demonstrated will be that of:
- A basic understanding of the webpages, websites, and the internal structuring of them.
- Simplistic usage of a DVCS via use of Git and Github.
- Basic understanding of HTML elements, tags, and the boilerplate needed for all HTML files.
- General text formatting and manipulation with emphasis (ha ha) on ***emphasis***.
- HTML lists both ordered and unordered.
- Links and images along with the basic attributes that go with them.
- Writing clear, concise, and helpful git commits for the DVCS.
